# 大钊 FDE 工作室

李钊（大钊）的个人工作室网站，以“让复杂系统更容易被人使用”为品牌主张。内容围绕企业 AI、Agent 产品规划、FDE 场景落地、产品与研发管理，以及可复用的知识资产展开。

## 本地运行

```bash
npm ci
npm run dev
```

开发服务器支持通过 CLI 参数指定监听地址和端口，例如：

```bash
npm run dev -- --host 127.0.0.1 --port 7100
```

## 构建与预览

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 7100
```

构建产物位于 `dist/`，为纯静态网站，无服务端、数据库或运行时密钥。Vite 使用相对资源路径，可部署到 GitHub Pages 的项目页路径。

## 已实现

- “大钊 FDE 工作室”品牌、卡通职业头像与响应式首屏
- 1.5 秒品牌过场、标题与头像分层入场、环境动效、头像鼠标视差、滚动进度与章节入场动效
- 可点击、支持键盘方向键的五阶段 FDE 工作链，以及面板切换和时间轴点亮动效
- “译间”Chrome 商店真实入口，不展示版本号或更新日期
- 三项实践／作品的原生对话框说明，支持关闭按钮、Esc 和背板点击
- 三部公开书稿的真实 PDF 下载与 GitHub 书稿仓库入口，FDE 内部评审草案不提供下载
- 微信二维码弹窗、微信号与邮箱复制、个人简介复制与 Markdown 下载
- 全部合作方向、四步合作流程及服务区域说明
- 职业路径与代表经历
- 默认品牌主题与可一键切换的白色主题，自动保存选择并适配深色章节、弹窗和移动端
- 移动端导航、可见焦点、减少动态效果偏好支持；减少动态效果时跳过品牌过场与环境动效

## 内容维护

- `src/data.ts`：工作链、项目、公开书稿与职业路径数据
- `src/pages/Home.tsx`：页面结构、品牌过场与交互
- `src/App.css`：组件与响应式样式
- `src/motion.css`：入场、视差、环境及滚动动效，包含减少动态效果降级
- `src/themes.css`：白色主题、主题切换按钮及深色章节的浅色适配
- `src/index.css`：OKLCH 色彩令牌、字体与全局样式
- `public/images/`：卡通头像、微信二维码等网站素材
- `public/books/`：经本人确认公开的三部 PDF 书稿
- `book-parts/`：《道德经新解》的三个二进制分段，用于绕过网页上传的单文件大小限制；GitHub Actions 会在构建前按顺序还原为原 PDF，分段文件不会发布到网站
- `public/downloads/lizhao-intro.md`：可下载的对外简介

主要事实依据为上级目录的《李钊-个人画像》V2.2、《李钊-对外自我简介》和《个人网站-信息补充》。参考 `https://imxiaoming.cn/` 的个人主页内容组织方式，但未复制其文案、配色、图片或代码。

## GitHub Pages 发布

仓库包含 `.github/workflows/deploy-pages.yml`。将本目录作为 GitHub 仓库根目录上传或推送后，在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。提交到 `main` 会触发构建与发布；也可以在 Actions 中手动运行工作流。

公开页面地址取决于实际仓库所有者与仓库名，未经验证前不要将预期地址当作已上线地址。

## 验收

发布前运行 `npm run lint` 检查全部项目源码，并在真实 Chromium 浏览器中检查 375、768、1024、1440 像素宽度。验收范围包括导航、工作链点击与键盘切换、项目及微信弹窗、复制、简介与书稿下载、资源加载和横向溢出。运行时依赖使用 `npm audit --omit=dev` 检查，当前无已知漏洞。
